Guia Prático: CLI Terminal

Dominar a linha de comando (CLI) é o primeiro passo para se tornar um usuário ou administrador eficiente no Linux. Abaixo, listei 30 comandos essenciais que você precisará usar, organizados para facilitar seus estudos.

Bloco 1: Navegação e Informações Básicas

pwd

Explicação: Mostra o caminho completo do diretório (pasta) onde você está no momento.

$ pwd

Uso: Ideal para saber "onde estou" antes de criar ou mover arquivos.

ls

Explicação: Lista todos os arquivos e pastas presentes no diretório atual.

$ ls -la

Uso: Use ls -l para detalhes e -a para arquivos ocultos.

cd

Explicação: Permite navegar e entrar em diferentes diretórios.

$ cd /var/log

Uso: Use cd .. para voltar e cd ~ para ir à pasta Home.

mkdir

Explicação: Cria uma nova pasta ou diretório.

$ mkdir projetos

Uso: Adicione -p para criar pastas dentro de pastas que não existem.

history

Explicação: Exibe o histórico de todos os comandos digitados recentemente.

$ history

Uso: Útil para lembrar um comando longo usado há alguns dias.

Bloco 2: Gerenciamento de Arquivos

touch

Explicação: Cria um arquivo vazio ou atualiza a data de modificação de um existente.

$ touch arquivo.txt

Uso: A forma mais rápida de criar um arquivo de texto novo.

cat

Explicação: Exibe o conteúdo de um arquivo de texto diretamente no terminal.

$ cat arquivo.txt

Uso: Bom para ler arquivos pequenos.

nano

Explicação: Um editor de texto simples e amigável direto no terminal.

$ nano arquivo.txt

Uso: Salve com Ctrl+O e saia com Ctrl+X.

cp

Explicação: Copia arquivos ou pastas de um lugar para outro.

$ cp arquivo.txt /backup/

Uso: Use -r para copiar pastas inteiras com tudo dentro.

mv

Explicação: Move arquivos/pastas de lugar ou simplesmente os renomeia.

$ mv arquivo.txt doc.txt

Uso: Serve tanto para mover ou renomear.

Bloco 3: Manutenção e Limpeza

rm

Explicação: Deleta arquivos ou pastas permanentemente.

$ rm arquivo.txt

Uso: Muito cuidado! Use rm -rf pasta para apagar uma pasta e tudo dentro.

rmdir

Explicação: Remove um diretório, desde que ele esteja totalmente vazio.

$ rmdir pasta_vazia

Uso: Comando seguro para apagar pastas que você tem certeza que estão vazias.

find

Explicação: Procura por arquivos ou diretórios em todo o sistema por vários critérios.

$ find /home -name "*.txt"

Uso: Extremamente útil para encontrar arquivos perdidos.

grep

Explicação: Busca por palavras ou padrões específicos dentro de arquivos.

$ grep "erro" log.txt

Uso: Ideal para ler relatórios longos (logs) e achar linhas rapidamente.

echo

Explicação: Exibe uma linha de texto no terminal ou grava texto em um arquivo.

$ echo "Olá Mundo" > ola.txt

Uso: Usado para criar arquivos rapidamente ou imprimir variáveis.

Bloco 4: Monitoramento do Sistema

df

Explicação: Mostra o espaço disponível e utilizado em seus discos.

$ df -h

Uso: A opção -h torna o tamanho legível (Human-readable) em Gigabytes.

du

Explicação: Mostra o tamanho exato de arquivos e pastas.

$ du -sh /documentos
